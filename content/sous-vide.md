低温調理器を使っても、私は大きく痩せませんでした。

でも、鶏むねは変わりました。鍋で茹でると固くなっていたものが、低温調理器だと柔らかく仕上がります。

先に結論を書きます。満足しているのは「鶏むねを柔らかく食べられること」です。不満は、お湯を温める時間を含めると、食べるまでに時間がかかることです。

この記事は、私が使っているBRUNOのコンパクト低温調理器の記録です。比較表にはPRISMATEとBONIQも載せていますが、**実際に使ったのはBRUNOだけ**です。他の2機種は、メーカーが公表している仕様と価格を並べています。

```

私の体験      私がBRUNOを使って実際に起きたこと
私の判断      体験と仕様から、私がそう考えていること
```

## 低温調理器で鶏むねは柔らかくなった

**私の体験**です。低温調理器を買う前、鶏むねは鍋で茹でるか、炊飯器で作るものだと思っていました。実際に鍋で茹でてみると、固くなってしまいました。

低温調理器で作るようになってからは、鍋で茹でたときより柔らかく仕上がっています。

作るのは主に休みの日です。かけるものはお好みですが、私はカオマンガイのようなネギだれで食べています。

**メーカー情報**です。BRUNOの公式レシピでは、鶏むね肉を次の条件で作っています。

```
BRUNO公式レシピの条件
  鶏むね肉   1枚250g程度
  厚さ      2〜2.5cm
  加熱      65℃・1時間
```

公式レシピには、**肉の厚みによって必要な加熱温度と加熱時間が異なる**とも書かれています。分量や厚さがこの条件と違うときは、取扱説明書の目安を確認してください。「65℃・1時間」だけを取り出して、別の肉に当てはめないでください。

## 低温調理器で鶏肉を作るときに、知っておきたいこと

低温調理は、普通の加熱より低い温度で肉に火を通します。そのぶん、温度と時間の管理が大事になります。ここは**公的機関の情報**です。

食品安全委員会は、肉の低温調理について次のように示しています。

```
加熱の条件（肉の内部の温度で数える）
  63℃  内部が63℃になってから、さらに30分
  70℃  3分
  75℃  1分
```

同じページには、**63℃のお湯で鶏むね肉を加熱したとき、肉の内部が63℃になるまで平均68分かかった**という調査結果も載っています。お湯が設定温度になっても、肉の中心はすぐにはその温度になりません。

食品安全委員会が挙げている注意は、ほかに3つあります。

- 肉の重さや大きさで、内部の温度の上がり方が変わる。特に厚いと時間が長くかかる
- 低温調理をするときは、中心温度計などで温度と時間を管理する
- 表面を焼いてアルミホイルで包むなど、**余熱を利用するレシピはやめる**

**私の判断**です。このため、次の3つを守るのが安全だと考えています。

1. メーカーの公式レシピを使うなら、分量と厚さも公式の条件にそろえる
2. 厚い肉や量の多いときは、公式の時間をそのまま使わず、取扱説明書を確認する
3. 火の通りに不安があるときは、中心温度計で肉の中心の温度を測る

この記事は、低温調理が安全かどうかを保証する記事ではありません。条件はメーカーの説明書と公的機関の情報を確認してください。

## 低温調理器のデメリットは時間がかかること

すすめる記事ですが、欠点も書いておきます。

**メーカー情報**です。BRUNOの公式サイトにある使い方は3つの手順です。

1. 温度と時間を設定して、予熱を始める
2. 設定温度に達したら、保存袋を鍋に入れる
3. 音が鳴ったら出来上がり

つまり公式レシピの「1時間」は、お湯が設定温度になってから数える時間です。お湯を温める予熱の時間は、公式サイトには書かれていませんでした。

そこでこの記事では、**調理時間を予熱＋1時間**と考えています。予熱にかかる時間は、私は測っていないので数字を出していません。

**私の体験**では、この時間の長さがいちばんの不満です。帰ってすぐ食べたい日には向かないので、使う回数は多くありません。

## 低温調理器を使っても私は痩せなかった

**私の体験**です。私は、低温調理器を使ったことで大きく痩せたわけではありません。

食べすぎた翌日に、鶏むねをおいしく食べられるようになりました。そのおかげで、食べすぎた後の気持ちの持ちようは変わりました。

今回比べたPRISMATEの商品名には「ダイエット」という言葉が入っています。ただ、これは商品の売り方の話で、低温調理器を使えば痩せるという根拠にはなりません。

**私の判断**です。低温調理器は「痩せるための道具」と考えるより、鶏むねなどをおいしく食べるための調理器具と考えたほうが、私の使用感には近いです。

## BRUNOの低温調理器は鍋が必要

**メーカー情報**です。BRUNOは、手持ちの鍋の縁にクリップで挟んで使う形で、鍋は付属していません。公式サイトの鍋の条件はこうです。

```
深さ   10cm以上
内径   16cm以上
容量   15L以下
```

水の量は、本体に付いているMINラインとMAXラインの間に合わせます（取扱説明書）。

たとえば直径25cmの鍋なら、内径の条件は満たしています。確かめるのは深さが10cmあるかどうかです。容量は、直径25cmの鍋で15Lを超えるには深さが約30cm必要なので、一般的な家庭の鍋で超えることはまずありません。

### PRISMATEとBONIQについて、仕様から分かること

**PRISMATE**は5,610円で、3機種の中で**鍋が付属しているのはこれだけ**です。鍋を持っていない人には候補になります。

ただし容量は約700mlです。鶏むね1枚250g程度を作りたい人に向くかは、容量という数字だけでは判断できません。温度も「やわらかモード」の約65℃（±5℃）に決まっていて、BRUNOのように1℃単位では変えられません。私は使っていないので、使い勝手も判断できません。

**BONIQ**は24,000円で、BRUNOより13,000円高い機種です。仕様で目立つ違いは、Wi-Fiでつなぐ専用アプリがあることです。温度の範囲はBRUNOと同じ5〜95℃でした。その差が何に効くかは、使っていないので判断できません。

## 低温調理器をおすすめする人・しない人

**おすすめする人**

- 鶏むねを茹でると固くなってしまう
- 休みの日に、予熱と1時間を待てる
- 温度と時間を、説明書どおりに守れる

**おすすめしない人**

- 使えば痩せると期待している
- 帰ってすぐ食べたい日に使いたい
- 分量や厚さを目分量で変えたい

## 低温調理器についてよくある質問

**Q. 低温調理器を使うと痩せますか？**
A. 私は大きく痩せていません。変わったのは、鶏むねをおいしく食べられるようになったことです。痩せるための道具として買うと、期待と違うかもしれません。

**Q. 鶏むねは何度で何時間ですか？**
A. BRUNOの公式レシピでは、1枚250g程度・厚さ2〜2.5cmの鶏むね肉を65℃で1時間です。これはお湯が設定温度になってからの時間で、予熱の時間は別にかかります。厚さや量が違うときは取扱説明書を確認してください。

**Q. 低温調理で鶏肉を食べても大丈夫ですか？**
A. この記事では安全を保証できません。食品安全委員会は、63℃なら肉の内部が63℃になってからさらに30分など、内部の温度と時間の条件を示しています。中心温度計などで温度と時間を管理することもすすめています。

**Q. 家にある鍋で使えますか？**
A. BRUNOの場合、公式の条件は深さ10cm以上・内径16cm以上・容量15L以下です。直径25cmの鍋なら内径は足りているので、深さを測ってください。

**Q. 袋は何を使えばいいですか？**
A. BRUNOの公式サイトには「保存袋に入れて、空気を抜くようにしっかりと密封」と書かれています。袋が水に完全に浸かるようにして使います。
