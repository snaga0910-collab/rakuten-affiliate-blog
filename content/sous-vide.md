低温調理器を使っても、私は大きく痩せませんでした。

でも、鶏むねは変わりました。鍋で茹でると固くなっていた鶏むねが、低温調理器では柔らかく仕上がります。

先に結論を書くと、私が満足しているのは「鶏むねを柔らかく食べられること」です。不満は、予熱を含めると食べるまでに時間がかかることです。

この記事では、私が使っているBRUNOのコンパクト低温調理器について、実際に使って分かったことを書きます。PRISMATEとBONIQも比較表に載せていますが、**実際に使ったのはBRUNOだけ**です。他の2機種は、メーカーが公表している仕様と価格を並べました。

低温調理は、肉の内部の温度と加熱時間の管理が重要です。そのため、情報の出どころを分けて書きます。

```
メーカー情報    BRUNOの公式サイト・取扱説明書、各商品ページ
公的機関の情報   食品安全委員会
私の体験       私がBRUNOを使って実際に起きたこと
```

## 低温調理器で鶏むねは柔らかくなった

低温調理器を買う前、鶏むねは鍋で茹でるか、炊飯器で作るものだと思っていました。実際に鍋で茹でてみると、固くなってしまいました。

低温調理器で作るようになってからは、鍋で茹でたときより柔らかく仕上がっています。これが、私がこの道具を使っている理由です。

作るのは主に休みの日です。かけるものはお好みですが、私はカオマンガイのようなネギだれで食べています。

## 低温調理器で鶏肉を作るときの温度と時間

ここはメーカーと公的機関の情報です。

### メーカーのレシピ条件

BRUNOの公式レシピの、鶏むね肉の条件は次のとおりです。

```
BRUNO公式レシピの条件
  鶏むね肉   1枚250g程度
  厚さ      2〜2.5cm
  お湯の温度  65℃
  時間      1時間（お湯が設定温度になってから）
```

公式レシピには、**肉の厚みによって必要な加熱温度と加熱時間が異なる**という注意もあります。分量や厚さが違うときは、取扱説明書の目安を確認してください。

### 公的機関が示している加熱条件

食品安全委員会が示している、肉の低温調理の条件は次のとおりです。

```
加熱の条件（肉の内部の温度と、その温度を保つ時間）
  63℃  内部が63℃になってから、さらに30分
  70℃  3分
  75℃  1分
```

### 2つの数字は、同じものを測っていません

ここがいちばん誤解しやすいところです。

```
BRUNOのレシピ      お湯の温度と、お湯に入れておく時間
食品安全委員会の条件  肉の内部の温度と、その温度を保つ時間
```

**お湯が設定温度になっても、肉の中心はすぐにはその温度になりません。** 食品安全委員会のページには、63℃のお湯で鶏むね肉を加熱したとき、肉の内部が63℃になるまで平均68分かかったという調査結果もあります。

そのため、「65℃・1時間」と「63℃・30分」を並べて、どちらが長い・短いと単純に比べることはできません。この記事では、BRUNOのレシピが食品安全委員会の示す条件を満たすかどうかを、独自に判定していません。

### 確認しておきたい点

メーカーと食品安全委員会の情報から、確認しておきたい点は次のとおりです。

- メーカーのレシピを使うなら、温度と時間だけでなく、分量と厚さも条件にそろえる（メーカー情報）
- 肉の重さや大きさで内部の温度の上がり方が変わり、厚いほど時間が長くかかる（公的機関の情報）
- 中心温度計などを使い、温度と、その温度を保った時間の両方を管理する（公的機関の情報）
- 表面を焼いてアルミホイルで包むなど、余熱を利用するレシピはやめる（公的機関の情報）

この記事は、低温調理の安全を保証するものではありません。実際に作るときは、メーカーの取扱説明書と食品安全委員会の情報を確認してください。

## 低温調理器のデメリットは時間がかかること

すすめる記事ですが、欠点も書いておきます。

BRUNOの公式サイトにある使い方は、3つの手順です。

1. 温度と時間を設定して、予熱を始める
2. 設定温度に達したら、保存袋を鍋に入れる
3. 音が鳴ったら出来上がり

公式レシピの「1時間」は、お湯が設定温度になってから数える時間です。お湯を温める予熱の時間は、公式サイトには書かれていませんでした。

そのため、**実際に食べるまでには、予熱の時間と公式レシピの1時間が必要**です。予熱にかかる時間は測っていないため、この記事では具体的な数字を出していません。

私にとっては、この時間の長さがいちばんの不満です。帰ってすぐ食べたい日には向かないので、使うのは主に休みの日です。

## 低温調理器を使っても私は痩せなかった

私は、低温調理器を使ったことで大きく痩せたわけではありません。

変わったのは、食べすぎた翌日に鶏むねをおいしく食べられるようになったことです。そのおかげで、食べすぎた後の気持ちの持ちようは変わりました。

今回比べたPRISMATEの商品名には「ダイエット」という言葉が入っています。ただ、これは商品の売り方の話で、低温調理器を使えば痩せるという根拠にはなりません。

私が使ってみた限りでは、低温調理器は痩せるための道具というより、鶏むねなどをおいしく食べるための調理器具です。

## BRUNOの低温調理器は鍋が必要

BRUNOは、手持ちの鍋の縁にクリップで挟んで使う形で、鍋は付属していません。公式サイトの鍋の条件はこうです。

```
深さ   10cm以上
内径   16cm以上
容量   15L以下
```

水の量は、本体に付いているMINラインとMAXラインの間に合わせます（取扱説明書）。

たとえば直径25cmの鍋なら、内径の条件は満たしています。確かめるのは深さが10cmあるかどうかです。容量は、直径25cmの鍋で15Lを超えるには深さが約30cm必要なので、一般的な家庭の鍋で超えることはまずありません。

## 低温調理器をおすすめする人・しない人

**おすすめする人**

- 鶏むねを茹でると固くなってしまう
- 休みの日など、食べるまでに時間をかけられる
- 温度・時間・分量を、説明書どおりに守れる

**おすすめしない人**

- 使えば痩せると期待している
- 帰ってすぐ食べたい日に使いたい
- 分量や厚さを目分量で変えたい

## 低温調理器についてよくある質問

**Q. 予熱が終わる前に、肉を入れてもいいですか？**
A. BRUNOの公式サイトの手順では、設定温度に達してから保存袋を鍋に入れることになっています。公式レシピの時間も、設定温度になってから数える前提です。

**Q. 公式レシピより厚い鶏むねのときは、どうすればいいですか？**
A. BRUNOの公式レシピには、肉の厚みによって必要な加熱温度と加熱時間が異なると書かれています。取扱説明書の目安を確認してください。食品安全委員会も、厚いほど中心部が同じ温度になるまで時間がかかるとしています。

**Q. 表面を焼いてから、余熱で火を通すレシピでもいいですか？**
A. 食品安全委員会は、余熱を利用するレシピでは肉の温度が食中毒を防げるほど上がらないとして、やめるよう呼びかけています。

**Q. 保存袋は、どう使えばいいですか？**
A. BRUNOの公式サイトには「保存袋に入れて、空気を抜くようにしっかりと密封」と書かれています。袋が水に完全に浸かるようにします。

**Q. 鍋はどれくらいの大きさが必要ですか？**
A. BRUNOの場合、深さ10cm以上・内径16cm以上・容量15L以下です。直径が足りていても、深さが10cmに届かない鍋は条件を満たしません。
