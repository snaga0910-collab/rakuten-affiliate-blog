食材宅配の広告には、たいてい大きな割引が出ています。「初回33%OFF」「お試し最大半額」「おためしセット1,980円」。

一人暮らしで自炊が続かないとき、この数字は魅力的に見えます。ただ3社の条件を公式サイトで並べると、**初回の安さは、続けるときの値段を示していませんでした**。

そして一人暮らしでは、料金より先に効いてくる条件があります。**届く量と、消費期限**です。

> **2026年9月19日に書き直しました。** 以前の版では「二人暮らしだと結論が逆になる」と書いていました。その後、シェフの無添つくりおきの価格が変わっていたこと、ヨシケイの料金は地域の販売会社ごとに違い全国共通の価格が出せないことが分かったため、その比較は取り下げました。この版では、**公式サイトで確認できた数字だけ**を使っています。

## まず前提：食材宅配3社は同じサービスではありません

| | 届くもの | 自分でやること |
|---|---|---|
| シェフの無添つくりおき | 調理済みの惣菜（冷蔵） | 温めるだけ |
| ヨシケイ | 食材とレシピ、または温めるコース | 作る／温める |
| Oisix | 食材（ミールキット含む） | 自分で作る |

読者が負担する作業が違うので、料金だけで順位はつけられません。まず自分がどれに近いかで候補が決まります。

- **もう作りたくない** → シェフの無添つくりおき
- **作るけど献立を考えたくない** → ヨシケイ
- **作るのは苦じゃないが買い物が面倒** → Oisix

私はこの3社を利用していません。この記事は公式サイトに書かれている内容の整理で、味やメニューの感想は含みません。

## 一人暮らしの食材宅配は、量と消費期限が先に効きます

| | 1回に届く量 | 消費期限・保存 |
|---|---|---|
| シェフの無添つくりおき（食卓サポートプラン） | 主菜2種＋副菜3種・約1kg（3人家族の2食分） | お届け日を含め4日間（一部エリアは3日間）。一部メニューを除き冷凍保存もできる |
| ヨシケイ | 毎日その日の分だけ | その日に使う前提 |
| Oisix | おためしセットは15品 | 商品ごとに違う |

**シェフの無添つくりおきは、一人暮らしには量が多い設計です。** 公式の目安は「3人家族（大人2名＋小人1名）の2食分」で、1人で食べると6食分ほどになります。これを消費期限の4日間で食べ切る前提です。

ただし公式では、一部のメニューを除いて冷凍保存もできるとされています。食べ切れない分を冷凍に回せるかは、届いたメニューごとに確認してください。

**ヨシケイは毎日その日の分だけ届く**ので、冷蔵庫を圧迫しません。ただし1人分から頼めるのは温めるコースと冷凍弁当で、包丁を使うミールキットは2人用からです（詳しくは[ヨシケイの記事](/articles/yoshikei)）。

## 食材宅配の料金：続けたときに計算できるのは1社だけでした

3社のうち、全国共通の数字で続けたときの料金を出せたのは、シェフの無添つくりおきだけです。

**シェフの無添つくりおき（食卓サポートプラン・2回目以降）**

```
5,173円（税込） ＋ 送料990円（税込） ＝ 1回 6,163円
1人で6食に分けて食べ切った場合 → 1食あたり 約1,027円
```

> **計算の前提**：公式の「3人家族の2食分」を、1人で6食に分けて食べ切ると仮定しました。**食べ切れなければ、その分だけ1食あたりは上がります。** 初回は「33%OFF・送料無料」と表示されていますが、実際の金額は申し込み画面で確認してください。

ヨシケイは、料金が地域の販売会社ごとに違います。全国共通の価格表が公式サイトにないため、この計算には入れていません。郵便番号を入れると、自分の地域の料金が表示されます。

Oisixは、定期の支払額が注文する中身で決まる仕組みで、送料も購入金額で変わります。週あたりの金額を1つに決められないため、ここでは計算していません。数字で確認できたのは、初めての人向けのおためしセット（1,980円・15品・送料無料）です。

**3社を同じ物差しの金額で並べることは、公式の情報だけではできませんでした。** そこで次の章から、1社ずつ「一人暮らしで何に気をつけるか」を書きます。

## シェフの無添つくりおきは、一人暮らしで食べ切れる？

調理済みの惣菜が冷蔵で届き、温めるだけで食べられます。自炊をやめられるのが、このサービスの価値です。

- 食卓サポートプランは5,173円（税込）で、2回目以降は送料990円がかかります
- 初回は送料無料で、「33%OFF」と表示されています
- 配送は週替わりです
- **初回分はキャンセルできません。** 2回目以降はいつでも解約でき、違約金はかかりません
- スキップは次回お届け日の6日前まで（九州・島根県・青森県は7日前まで）です

一人暮らしで気をつけるのは量です。6食分ほどを4日間で食べる前提なので、平日に外食が入る週は余りやすくなります。冷凍できるメニューがあるかは、届いたものごとに確認してください。

- **向いている人**・料理をする時間も気力もない人。量を食べる人
- **向かない人**・4日で6食分を食べ切る自信がない人。1食あたりを抑えたい人

→ [プランの内容と2回目以降の金額を確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+CC5EU2+57YO+61Z81)

## ヨシケイは、一人暮らしで何が頼める？

毎日その日の分だけ届き、入会金と配達料はかかりません。不在の日は、鍵付きのあんしんBOXに置き配してもらえます。

一人暮らしで注意するのは、頼めるコースです。

```
1人分から頼める   Yデリ（地域によりタイムリーミール）と冷凍弁当
2人用から        包丁を使うミールキット
```

料金とコース名、注文締切は地域の販売会社ごとに違います。郵便番号を入れて、自分の地域のページで確認してください。

- **向いている人**・温めるだけでよく、1食から頼みたい人。冷蔵庫が小さい人
- **向かない人**・作るミールキットを1人分だけ頼みたい人。平日に受け取れず、置き配もできない人

→ [お試し5daysの価格と選べるコースを確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+DKSX7E+1QM6+IA7ZL)

## Oisixのおためしセットは、自動で続く？

おためしセットは1,980円（税込）で15品、送料無料です。初めての人が1回だけ使えるセットで、**自動では定期にならない**と公式に書かれています。続けたい場合は、自分で定期の申し込みをします。

定期にすると、毎週Oisixが用意する定期ボックスの中身を、自分で見て変えてから届く形になります。支払額は選んだ中身で決まり、送料も購入金額で変わります。

- **向いている人**・買い物の手間を減らしたい人。まず1回だけ試したい人
- **向かない人**・毎週の支出を固定したい人。中身を選ぶ手間もかけたくない人

→ [おためしセットの中身と定期の条件を確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+D1R1UI+3RK+2TSWQ9)

## 食材宅配を申し込む前に確認すること

1. **配達エリアに入っているか。** 3社とも郵便番号で確認できます
2. **受け取れるか。** ヨシケイは毎日配達、シェフの無添つくりおきは週替わりの配送です。置き配の可否も確認してください
3. **冷蔵庫に入る量か。** シェフの無添つくりおきは約1kgが一度に届きます
4. **2回目以降の金額。** 初回の割引や送料無料は、2回目から外れます

4番がいちばん見落とされます。シェフの無添つくりおきは、2回目から送料990円が乗ります。

## よくある質問

**Q. 初回だけ使ってやめられますか？**
A. 3社とも初回だけで止めることはできます。ただしシェフの無添つくりおきは、初回分のキャンセルはできず、2回目以降を止める形です。Oisixのおためしセットは自動で定期にならない買い切りです。

**Q. 一人暮らしだと、どれがいちばん安いですか？**
A. 公式の情報だけでは、同じ物差しで比べられませんでした。ヨシケイは料金が地域で違い、Oisixは中身で支払額が変わるためです。計算できたのはシェフの無添つくりおきで、1人で6食に分けた場合は1食あたり約1,027円です。

**Q. 食べ切れなかったらどうなりますか？**
A. シェフの無添つくりおきの消費期限は、お届け日を含め4日間（一部エリアは3日間）です。一部メニューを除いて冷凍保存もできるとされています。食べ切れない分は、1食あたりの実質の金額を押し上げます。

**Q. 自炊よりは高いですよね？**
A. 高いです。この記事は「自炊しない日の選択肢どうし」の比較で、自分で買い物して作る場合とは比べていません。コンビニ弁当や外食と比べる商品だと考えてください。

**Q. 二人暮らしならどうですか？**
A. シェフの無添つくりおきは1回の配送量が決まっているので、二人で分ければ1人あたり1回約3,082円です。ヨシケイは2人用から作るコースを頼めるようになりますが、料金は地域で違うため、この記事では比べていません。

## 結論：まず「作りたいかどうか」を決める

料金を同じ物差しで並べられない以上、選ぶ順番は料金ではなく、自分がどこまでやりたいかです。

- **もう作りたくない** → [シェフの無添つくりおき](https://px.a8.net/svt/ejp?a8mat=4BA9HF+CC5EU2+57YO+61Z81)。帰ってすぐ食べられる状態を買うサービスです。4日で食べ切れる量か、冷凍に回せるかだけ確認してください
- **作るけど献立は考えたくない** → [ヨシケイ](https://px.a8.net/svt/ejp?a8mat=4BA9HF+DKSX7E+1QM6+IA7ZL)。毎日その日の分だけ届きます。一人暮らしなら、1人分で頼めるのは温めるコースと冷凍弁当です
- **買い物だけ減らしたい** → [Oisix](https://px.a8.net/svt/ejp?a8mat=4BA9HF+D1R1UI+3RK+2TSWQ9)。おためしセット1,980円は自動で定期になりません

どれを選んでも、**初回の値段で判断しないこと**。2回目以降を続けられるかで決めてください。
