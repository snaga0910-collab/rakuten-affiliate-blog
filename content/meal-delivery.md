食材宅配の広告には、必ず大きな割引が出ています。「初回33%OFF」「お試し5days 最大50%OFF」「おためしセット1,980円」。

一人暮らしで自炊が続かないとき、この数字は魅力的に見えます。ただ3社の条件を並べて計算したところ、**初回の安さは、続けるときの値段をまったく示していませんでした**。

そして一人暮らしには、料金より先に効いてくる条件がありました。**届く量と、消費期限**です。

## 先に結論：初回と2回目以降で1.8〜2.7倍になります

| | 初回 | 2回目以降 | 倍率 |
|---|---|---|---|
| [ヨシケイ](https://px.a8.net/svt/ejp?a8mat=4BA9HF+DKSX7E+1QM6+IA7ZL) | 1,500円（5日分） | 3,000円（5日分） | **2.0倍** |
| [Oisix](https://px.a8.net/svt/ejp?a8mat=4BA9HF+D1R1UI+3RK+2TSWQ9) | 1,980円（15品） | 週5,400円〜（2人前） | **2.7倍〜** |
| [シェフの無添つくりおき](https://px.a8.net/svt/ejp?a8mat=4BA9HF+CC5EU2+57YO+61Z81) | 3,280円 | 5,828円 | **1.8倍** |

**初回がいちばん高いシェフの無添つくりおきが、倍率ではいちばん小さい**という結果でした。

割引率だけを見ると逆の印象になります。ヨシケイは「最大50%OFF」、Oisixは「74%OFF相当」と表示されていますが、**割引が大きいほど、通常価格との落差も大きい**という当たり前のことが起きているだけです。

## この記事が役に立たない人

- **家族で使う人**：この記事は**一人暮らし**が前提です。3社とも2〜4人前を基本にしているので、家族なら1食あたりの単価はもっと下がります
- **味やメニューを知りたい人**：この記事は料金と契約条件の比較です。**私はこの3社を利用していません**。公表されている料金表と各社の案内からの整理で、実食の感想は書いていません
- **冷凍で長く置きたい人**：ここで比べた3社は**冷蔵**が中心です。冷凍弁当を探しているなら別のサービスを見てください

## 3社は、そもそも別のものを売っています

料金を比べる前に、ここを揃えないと意味がありません。

| | 届くもの | 自分でやること |
|---|---|---|
| シェフの無添つくりおき | **調理済みの惣菜** | 温めるだけ |
| ヨシケイ | **食材＋レシピ** | 10〜15分で調理 |
| Oisix | **食材（ミールキット含む）** | 自分で作る |

**「自炊をどこまでやめたいか」で選ぶ商品**です。値段だけ並べても、比べているものが違います。

- **もう作りたくない** → シェフの無添つくりおき
- **作るけど献立を考えたくない** → ヨシケイ
- **作るのは苦じゃないが買い物が面倒** → Oisix

## 一人暮らしで効くのは、量と消費期限です

ここが料金より先に効きます。

| | 内容量 | 消費期限 |
|---|---|---|
| シェフの無添つくりおき（食卓サポート） | 主菜2種＋副菜3種・約1kg（**3人前×2食分**） | **届いた日を含め3日間**（一部地域4日） |
| ヨシケイ | 1日1食分×5日（**毎日配達**） | その日に使う前提 |
| Oisix | おためしは15品 | 商品による |

**シェフの無添つくりおきは、一人暮らしには量が多いです。** 3人前×2食分＝実質6食分が、**3日で消費期限を迎えます**。1人で3日以内に6食分を食べ切る前提になります。

食べ切れなければ捨てることになるので、**1食あたりの実質単価はさらに上がります**。

**ヨシケイは毎日配達**なので、この問題が起きません。月〜金の5日間、その日の分だけ届きます。一人暮らしの冷蔵庫事情には、こちらのほうが合っています。

## 2回目以降の1食あたりを計算しました

継続したときに実際いくら払うのかを出します。

**シェフの無添つくりおき（食卓サポートプラン）**

```
2回目以降 4,838円 ＋ 送料990円 ＝ 5,828円
1人で食べ切ると仮定して6食分 → 1食あたり約971円
```

**ヨシケイ（プチママ等・2人前で注文した場合の1人分）**

```
1食600円 × 5日 ＝ 3,000円
配達料は無料 → 1食あたり600円
```

**Oisix（定期ボックス・2人前）**

```
週5,400〜9,900円 → 1人分に直すと週2,700〜4,950円
週5食とみて1食あたり540〜990円
```

> **計算の前提**：一人暮らしが1週間使った場合で、**送料を含みます**。シェフの無添つくりおきは「3人前×2食分」を1人で6食に分けて食べ切ったとして計算しました。**食べ切れなければ、その分だけ実質単価は上がります。** Oisixの定期ボックスは注文内容で金額が大きく変わるため、公表されている幅をそのまま使いました。ヨシケイは人数と地域で単価が変わります。

**惣菜が届くシェフの無添つくりおきは、やはり高くつきます。** ただしこれは「調理済み」への対価なので、**同じ条件で比べた高い安いではありません**。

## シェフの無添つくりおき：作るのをやめたい人向け

**調理済みの惣菜が冷蔵で届きます。** 温めるだけで食べられるので、**自炊を完全にやめられる**のがここだけの価値です。

初回3,280円（送料無料）、2回目以降4,838円＋送料990円。**回数縛りはなく、1回でやめられます**。合わなければ初回だけで止められるので、試すハードルは低いです。

弱点は2つあります。

**① 一人暮らしには量が多い。** 食卓サポートプランでも3人前×2食分で、**消費期限は届いた日を含め3日間**（一部地域4日）です。冷蔵なので冷凍して先送りする前提ではありません。

**② 2回目から送料990円がかかります。** 初回は無料なので、初回価格だけ見ていると見落とします。

- **向いている人**：料理をする時間も気力もない人。量を食べる人
- **向かない人**：3日で食べ切る自信がない人。1食あたりを抑えたい人

→ [プランの内容量と2回目以降の金額を確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+CC5EU2+57YO+61Z81)

## ヨシケイ：一人暮らしの冷蔵庫と相性がいい

**食材とレシピが、月〜金の毎日届きます。** 10〜15分で作れる分量で、**その日の分だけ**なので冷蔵庫を圧迫しません。

**配達料は無料**で、入会金もかかりません。**定期縛りもなく**、キャンセルは配達日の前週水曜17時までです。

お試し5daysは**通常価格の最大半額**で、**ヨシケイをはじめて利用する人限定**です。

通常価格は人数で変わります。**1人で頼むほど割高**になり、2人前で注文した場合の1人分が1食600円前後です。ここは一人暮らしには不利な設計です。

- **向いている人**：作るのは苦じゃないが献立を考えたくない人。冷蔵庫が小さい人
- **向かない人**：まったく作りたくない人。平日に受け取れない人

→ [配達エリアと人数ごとの通常価格を確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+DKSX7E+1QM6+IA7ZL)

## Oisix：買い物をやめたい人向け

**おためしセットは1,980円で15品**、送料無料です。**自動的に定期購入にはなりません**——買い切りなので、そのまま何もしなければ課金は発生しません。**3社でいちばん試しやすい**設計です。

ただし継続すると話が変わります。定期ボックスは**2人前で週5,400〜9,900円**と幅が広く、注文内容で大きく動きます。おためしとの倍率は2.7〜5.0倍で、**3社で最も落差が大きい**です。

- **向いている人**：買い物の手間を減らしたい人。まず試すだけしてみたい人
- **向かない人**：毎週の支出を固定したい人。少量だけ欲しい人

→ [おためしセットの中身と定期の条件を確認する](https://px.a8.net/svt/ejp?a8mat=4BA9HF+D1R1UI+3RK+2TSWQ9)

## 申し込む前に確認すること

料金以前の話です。

1. **配達エリアに入っているか**。ヨシケイは地域の販売会社が配達するので、エリア外だと申し込めません
2. **平日の日中に受け取れるか**。ヨシケイは毎日配達、シェフの無添つくりおきは週1回の定期配送です。置き配の可否も確認してください
3. **冷蔵庫に入る量か**。シェフの無添つくりおきは約1kg届きます
4. **2回目以降の送料**。シェフの無添つくりおきは990円かかります

**4番が見落とされます。** 初回無料の表示に隠れて、**継続時の実質価格が変わります**。

## よくある質問

**Q. 初回だけ使ってやめられますか？**
A. シェフの無添つくりおきは回数縛りがなく、1回で解約できます。Oisixのおためしセットは買い切りで、自動継続しません。ヨシケイも定期縛りはありません。**3社とも、初回だけ試すことは可能です。**

**Q. 一人暮らしだと結局どれが安いですか？**
A. 継続時の1食あたりで見ると、ヨシケイ（約600円）とOisix（540〜990円）が近く、シェフの無添つくりおき（約971円）が高くなります。ただし**シェフの無添つくりおきだけ調理済み**なので、同じ条件の比較ではありません。

**Q. 食べ切れなかったらどうなりますか？**
A. シェフの無添つくりおきは冷蔵で消費期限が3日（一部地域4日）です。冷凍保存は想定されていないので、**食べ切れない分は捨てることになり、実質単価が上がります**。量を食べない人は注意してください。

**Q. 送料はいくらかかりますか？**
A. ヨシケイは配達料無料です。シェフの無添つくりおきは初回無料、2回目以降990円。Oisixは購入額が一定を超えると無料になります。

**Q. 自炊よりは高いですよね？**
A. 高いです。この記事で比べたのは「自炊しない場合の選択肢どうし」で、自分で買い物して作る場合とは比べていません。**コンビニ弁当や外食と比べる商品**だと考えてください。

**Q. 一人暮らしでも申し込めますか？**
A. できます。ただし3社とも2〜4人前が基本の設計なので、**1人だと1食あたりが割高になります**。ヨシケイは人数を選べますが、少人数ほど単価が上がります。

## 結論：まず「作りたいかどうか」を決める

3社を並べて分かったのは、**値段の比較にあまり意味がなかった**ということでした。売っているものが違うからです。

- **もう作りたくない** → **[シェフの無添つくりおき](https://px.a8.net/svt/ejp?a8mat=4BA9HF+CC5EU2+57YO+61Z81)**。1食あたりは高いですが、調理がゼロになります。3日で食べ切れる量かだけ確認してください
- **作るけど献立は考えたくない** → **[ヨシケイ](https://px.a8.net/svt/ejp?a8mat=4BA9HF+DKSX7E+1QM6+IA7ZL)**。毎日配達なので冷蔵庫を圧迫せず、配達料も無料です
- **買い物だけ減らしたい** → **[Oisix](https://px.a8.net/svt/ejp?a8mat=4BA9HF+D1R1UI+3RK+2TSWQ9)**。おためし1,980円は自動継続しないので、いちばん気軽に試せます

**どれも初回は安く、2回目から1.8〜2.7倍になります。** 初回価格で判断せず、**2回目以降を続けられる金額かどうか**で決めてください。
