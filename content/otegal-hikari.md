おてがる光には、**違約金がありません**。公式のよくある質問に「おてがる光には違約金の設定はありません」と書かれています。

ただし、解約にお金がかからないわけではありません。やめ方によっては、次の2つがかかります。

- 工事費の分割払いが終わる前にやめると、**残りを一括で払う**
- 解約が完了するのは受付の**翌月末日**で、その月まで料金がかかる

この記事は、おてがる光の重要事項説明書（2026年6月17日改定）、契約約款、公式のよくある質問をもとに整理しました（2026年10月11日確認）。**私はおてがる光を使っていません**。使い心地や速度の感想は書いていません。

## 結論：解約でかかる費用は、条件によって最大5つ

| 費用 | 金額 | かかる条件 |
|---|---|---|
| 違約金 | 0円 | かからない |
| 工事費の残り | 最大22,000円 | 工事費の11回払いが終わる前にやめたとき |
| 退会完了月までの月額 | マンション3,608円／戸建て4,708円 | 受付の翌月末日まで必ずかかる |
| 回線の撤去工事費 | 重要事項説明書に金額の記載なし | 撤去工事が必要になったとき |
| 機器の料金 | 重要事項説明書に金額の記載なし | 機器を返却しなかったとき |

> 金額は税込です。出典：[重要事項説明書](https://otegal.jp/rules/important-matters.pdf)、[おてがる光を解約した場合の違約金を教えてください｜おてがる光 よくある質問](https://otegal.jp/support/qanswer/question13.html)

この中で金額が大きく、しかも時期で変わるのは、工事費の残りと退会完了月までの月額です。この2つを順に説明します。

## 工事費の残りは、払い終えた回数で決まる

重要事項説明書では、新規工事の工事費は次のとおりです。

| 工事の種類 | 一括払い | 分割払い |
|---|---|---|
| 集合住宅（新規工事） | 22,000円 | 2,000円×11回 |
| 戸建て（新規工事） | 22,000円 | 2,000円×11回 |
| 集合住宅・戸建て（無派遣工事） | 3,300円 | なし |
| おてがる光クロス（派遣工事） | 26,400円 | 1,100円×24回 |

分割払いの途中で解約すると、**払っていない残りを一括で払います**（重要事項説明書）。集合住宅・戸建ての新規工事なら、残りは次のとおりです。

| 払い終えた回数 | 解約時に一括で払う残り |
|---|---|
| 0回 | 22,000円 |
| 1回 | 20,000円 |
| 3回 | 16,000円 |
| 6回 | 10,000円 |
| 9回 | 4,000円 |
| 10回 | 2,000円 |
| 11回 | 0円 |

> 計算は「22,000円 − 2,000円 × 払い終えた回数」です。分割払いが開通した月から始まるのか、翌月から始まるのかは、重要事項説明書からは読み取れませんでした。自分が何回払い終えたかは、毎月の請求の明細で確認してください。

### 「工事費実質無料」は、払い終えるまで使い続けた場合だけ

おてがる光のキャンペーンページには、新規工事費を分割払いにした人は、分割払いと同じ額の月額割引を最大12か月間受けられると書かれています。毎月2,000円の分割払いと同じ額が割り引かれるので、使い続けている間は、工事費の負担が実質0円になる仕組みです。

ただし同じページに、割引は「適用期間終了まで各サービスの契約中で有る事が条件」とあります。途中でやめると割引はそこで終わり、分割の残りは一括で請求されます。**実質無料になるのは、分割払いが終わるまで使い続けた場合だけ**です。

> キャンペーンページには、別の箇所に、マンションタイプの派遣費用を16,500円（1,375円を最大12回割引）とする記載もあり、重要事項説明書の金額（22,000円・11回）と食い違っていました。この記事は、契約内容を定めた重要事項説明書の金額で計算しています。申し込む人は、申し込み画面で自分の工事費を確かめてください。出典：[おてがる光 キャンペーンページ](https://otegal.jp/price/)

## 解約が完了するのは「受付の翌月末日」

重要事項説明書には、次のように書かれています。

```
退会完了となるのは、当社が退会の受付をした月の翌月末日
退会完了月まで、月額料金を含むすべての料金が発生する
```

受付は、電話をかけた時点ではありません。解約を申し込むと、確認事項を書いたメールが届きます。**そのメールに返信した時点で受付**になります。

| 受付した日 | 退会完了日 | 月額がかかる月 |
|---|---|---|
| 3月1日 | 4月30日 | 3月・4月 |
| 3月20日 | 4月30日 | 3月・4月 |
| 3月31日 | 4月30日 | 3月・4月 |
| 4月1日 | 5月31日 | 4月・5月 |

同じ月のうちなら、月の初めに受付しても月末に受付しても、退会完了日は変わりません。**迷っているうちに月をまたぐと、1か月分（マンションなら3,608円）多く払う**ことになります。やめると決めたら、その月のうちに受付まで済ませてください。

運営会社のサイトの解説記事では、月末は電話がつながりにくいことがあるので、解約したい月の前月上旬までに手続きするようすすめています。

> 撤去工事をする場合は、退会完了日が「撤去工事が完了した月の末日」になります（重要事項説明書）。

## 解約の手順

重要事項説明書に書かれている窓口は、電話とメールです。

```
電話   おてがる光カスタマーセンター 0120-921-301（10:00〜19:00）
メール  info@otegal.jp
```

1. カスタマーセンターに解約を申し込む（本人確認があります）
2. 確認事項を書いたメールが届くので、返信する（ここで受付）
3. 機器の回収キットが、機器を置いている住所に届く
4. 案内に従って、回線終端装置などの機器を返却する

運営会社のサイトの解説記事では、電話のほかにLINEと問い合わせフォームからも手続きできると案内しています。

### 機器を返さないと、機器の料金を請求されることがある

重要事項説明書には、設置機器の返却がない場合は「機器料金を請求させていただく場合があります」と書かれています。回収キットが届いたら、早めに返却してください。

### 撤去工事が必要になる場合

退会にともなって、回線の撤去工事費がかかる場合があります（重要事項説明書）。契約約款では、建物の回復や撤去工事が必要な場合、その費用は契約者の負担と決められています。

賃貸の場合、撤去工事が必要かどうかは管理会社や大家さんの判断です。解約を申し込む前に、管理会社に確認してください。撤去工事費の金額は重要事項説明書には書かれていません。運営会社のサイトの解説記事では、5,500円〜11,000円としています。

## ほかの光回線に乗り換えるとき（事業者変更）

フレッツ光の回線をそのまま使うほかの光回線（光コラボ）に乗り換えるときは、今の契約先から「事業者変更承諾番号」をもらい、乗り換え先で申し込みます。重要事項説明書に書かれている条件は次のとおりです。

- **開通した月は、承諾番号を申し込めない**。開通の翌月以降に手続きする
- 承諾番号の有効期限は**14日間**。過ぎたら取り直しになる
- 2022年6月以前に契約した人は、発行手数料3,300円がかかる
- 支払期日を過ぎた未払いがあると、払い終えるまで発行されない
- 工事費の分割払いの途中なら、**残りを一括で払う**

## 申し込んで8日以内なら「初期契約解除」

この契約は、初期契約解除制度の対象です。郵送かメールで届く「おてがる光会員登録証」を受け取った日から8日を経過するまでは、書面を郵送して契約を解除できます（重要事項説明書）。

この場合、違約金や損害賠償はかかりません。ただし、契約事務手数料と、すでに工事をしていればその工事費は請求されます。月額料金は日割りで請求され、キャンペーンは適用されません。

## 契約を検討している人へ：おてがる光が向いている人

契約期間の縛りがなく、いつやめても違約金を払わずに済む光回線です。

ただし、分割払い（11回）が終わる前にやめると、残りを一括で払います。

- **向いている人**：1〜2年で引っ越すかもしれないが、11か月以上は住む見込みがある人
- **注意が必要な人**：数か月以内に引っ越す可能性が高い人（分割の残りがかかる）

マンションの月額は3,608円です。ほかの光回線と、違約金・工事費の残り・スマホのセット割まで比べた結果は、[一人暮らしの光回線4社比較](/articles/hikari-internet)に載せています。

申し込む人は、申し込みページで最新の料金・工事費・キャンペーンの条件を確認してください。

## おてがる光の解約についてよくある質問

**Q. 最低利用期間はありますか？**
A. 重要事項説明書と契約約款には、最低利用期間や違約金の定めはありませんでした。公式のよくある質問でも、違約金は「無料」と回答しています。ほかのサイトに「2年の最低利用期間がある」と書かれていることがありますが、今回確認した公式の資料とは食い違います。

**Q. 解約月の料金は日割りになりますか？**
A. 日割りの前に、退会完了日が「受付した月の翌月末日」と決まっています。退会完了月まで、月額料金を含むすべての料金がかかります。

**Q. 月の途中で申し込むと損ですか？**
A. 同じ月のうちなら、いつ受付しても退会完了日は翌月末日で変わりません。損になるのは、月をまたいで受付が遅れた場合です。

**Q. 引っ越し先でも続けられますか？**
A. 重要事項説明書には、引っ越しの手続き中は事業者変更承諾番号の発行が手続き完了後になる、という記載があります。引っ越し先で続ける条件や費用は、カスタマーセンターで確認してください。

**Q. 分割の残りをなくす方法はありますか？**
A. 重要事項説明書の範囲では、分割払いの途中でやめた場合の免除の条件は見つかりませんでした。運営会社のサイトの解説記事には、乗り換え先によっては残りを負担する特典がある場合がある、と書かれています。乗り換え先のキャンペーンを確認してください。

## まとめ

- 違約金はない（公式のよくある質問）
- 工事費の分割払い（2,000円×11回）が終わる前にやめると、残りを一括で払う
- 退会完了は受付した月の翌月末日。その月まで料金がかかるので、やめると決めたら月内に受付まで済ませる
- 機器は回収キットで返却する。返さないと機器の料金を請求されることがある
- 乗り換えの承諾番号は開通の翌月以降に取れ、有効期限は14日間

11回払いを終えてからやめれば、かかるのは退会完了月までの月額だけです。
