ahamo光の解約金は、1ギガならマンションタイプ**3,630円**、戸建タイプ**4,950円**です。契約満了月とその翌月・翌々月の3か月間は、解約金がかかりません。

ただし、解約金が0円でも、工事料の残りが請求されたり、工事料実質0円特典のdポイントを全額受け取れなかったりする場合があります。

スマホのahamoもやめる場合は、ahamo光のペア回線の手続きも必要です。放置すると、後日強制解約になります。

この記事は、ドコモの公式サイトとドコモが出している注意事項のPDFだけで整理しました（2026年10月12日確認）。**私はahamo光を使っていません**。速度や使い心地の感想は書いていません。

まず、自分がどのケースかを確認してください。やることが違います。

| あなたのケース | 最初にやること | 読む章 |
|---|---|---|
| 光回線だけやめる（スマホのahamoは続ける） | ドコモの解約ページで申し込む | 解約金・工事料・解約手順 |
| ほかの光回線に乗り換える | ドコモで承諾番号を取る | 乗り換えるとき |
| スマホのahamoもやめる・他社に乗り換える・プランを変える | 先にahamo光のペア回線の設定を解除する | スマホのahamoをやめると |

| 費用 | 金額（税込） | かかる条件 |
|---|---|---|
| 解約金（1ギガ） | マンション3,630円／戸建4,950円 | 2年の定期契約の途中でやめたとき（更新期間は0円） |
| 解約金（10ギガ） | 5,610円 | 同上 |
| 解約月の基本料 | 1か月分 | 日割りにならない |

## 解約金は、2年ごとの更新期間なら0円

先に1つだけ。更新期間に解約して解約金が0円でも、**工事料の残りや、受け取れなくなるdポイントの分は別にかかります**。解約金0円は、解約の負担が0円という意味ではありません。

定期契約プランは2年契約で、やめる申し出がなければ自動で更新されます。

**解約金（定期契約プラン・税込）**

| プラン | 戸建タイプ | マンションタイプ |
|---|---|---|
| ahamo光 1ギガ | 4,950円 | 3,630円 |
| ahamo光 10ギガ | 5,610円 | 5,610円 |

契約満了月の当月・翌月・翌々月の3か月は、解約金がかかりません。自分の契約満了月は、My docomoで確認できます。

気をつけたいのは、**ahamo光の契約期間と、スマホのahamoの契約期間は別々に扱われる**ことです。公式の案内には、スマホ側の契約期間の満了に合わせてahamo光をやめても、ahamo光の解約金がかかる場合があると書かれています。

**月額（税込・2026年10月12日に[ahamo光の公式ページ](https://www.docomo.ne.jp/internet/ahamo_hikari/)で確認）**

| プラン | 定期契約あり（2年） | 定期契約なし |
|---|---|---|
| 1ギガ マンションタイプ | 3,630円 | 4,730円 |
| 1ギガ 戸建タイプ | 4,950円 | 6,600円 |
| 10ギガ（戸建・マンション共通） | 5,610円 | 7,260円 |

> 定期契約ありの月額は、公式ページの料金の画像（2年定期契約の場合）で確認しました。定期契約ありの解約金は、月額のちょうど1か月分と同じ金額です。

## 「工事料実質0円」は、途中でやめると0円にならない

新規に申し込むと、工事料と同じ額のdポイントがもらえる「新規工事料実質0円特典」があります。ただし、dポイントは一度にもらえません。

| 申し込んだ日 | 工事料（屋内配線工事あり） | dポイントのもらい方 |
|---|---|---|
| 2026年6月1日以降 | 28,600円 | 開通した月の7か月後から、24か月に分けて |
| 2026年5月31日まで | 22,000円 | 開通した月の1か月後から、24か月に分けて |

そして、特典をもらっている途中で解約すると、**解約月の翌月からdポイントの付与が止まります**。工事料そのものは請求されるので、もらえなかった分はそのまま自分の負担です。

2026年6月1日以降に申し込んだ場合、ドコモの特典ページには次の例が載っています。

```
1月に開通した場合
  8月（開通月を1か月目として8か月目）  1,207pt
  9か月目〜31か月目               1,191ptずつ
  合計                         28,600pt
```

この例をもとに、何か月目に解約するとどれだけ受け取れるかを試算しました。下の表は確定した金額ではなく、試算です。

| 開通月を1か月目として、解約した月 | 受取ポイントの試算 | 実質負担の試算 |
|---|---|---|
| 7か月目まで | 0pt | 28,600円 |
| 8か月目 | 1,207pt | 27,393円 |
| 12か月目 | 5,971pt | 22,629円 |
| 24か月目 | 20,263pt | 8,337円 |
| 31か月目 | 28,600pt | 0円 |

> **計算の前提**：受け取れるポイントは「1,207pt ＋ 1,191pt ×（解約した月 − 8）」です（8か月目〜31か月目に解約した場合）。特典ページの「特典進呈期間中に解約となった場合、解約月の1か月後の月から付与は終了」という文言にしたがって、解約した月の分までは受け取れる前提で数えています。dポイントは期間・用途限定で、有効期限は進呈月を含む6か月です。現金とは違い、使い道が限られます。出典：[ahamo光 新規工事料実質0円特典｜NTTドコモ](https://www.docomo.ne.jp/campaign_event/ahamo_hikari_shinkikojiryo_free/)、[工事料と特典の改定のお知らせ｜NTTドコモ](https://www.docomo.ne.jp/info/notice/page/260423_00.html)

まとめると、公式の進呈例では、進呈は**8か月目に始まり、24回目の31か月目で合計28,600pt**です。上の表は、この進呈例と付与終了の文言から計算した**試算**です。解約した月の分が実際に進呈されるかは、進呈日と解約日の扱いによります。区切りの月に解約するなら、My docomoで進呈の予定を確かめてください。いずれにしても、全額に届くまでの期間は2年の契約期間より長くなります。1〜2年でやめる可能性があるなら、工事料の一部は自分で負担すると考えておいてください。

2026年5月31日までに申し込んだ人は、開通月の1か月後（2か月目）から24か月でもらい終わります。工事料22,000円を同じ考え方で24回に分けると、12か月目に解約した場合に受け取れるのは約10,100pt、実質負担は約11,900円です。22,000円の場合の進呈例は特典ページに載っていないため、計算上の目安です。

> ahamo光の紹介ページには、工事料を「戸建・マンション22,000円」とする記載が残っていました。ドコモは2026年4月23日のお知らせで、6月1日以降の申し込みから28,600円に改定すると発表しています。この記事は、改定のお知らせの金額で計算しています。

## スマホのahamoをやめると、ahamo光はどうなる？

この光回線は、スマホのahamo回線を「ペア回線」として設定していることが契約の条件です。そのため、次のどれかをすると、契約を続けられなくなります。

- スマホのahamoを解約する
- ほかの携帯会社に乗り換える（ドコモのPDFの表記では「解約（MNP予約を含む）」）
- ahamoからドコモMAX・ドコモminiなど、ahamo以外のプランに変える

ドコモの注意事項のPDF（2026年7月版）では、手続きの順番が決まっています。スマホのahamoを解約する場合の流れは、次のとおりです。

1. [ペア回線の手続きのPDF](https://www.docomo.ne.jp/binary/pdf/internet/hikari/notice/ahamohikari_step_notice.pdf)で、自分のパターンを確認する
2. ahamo光のペア回線の設定を解除する
3. スマホのahamoを解約する（MNP予約を含む）。プラン変更の場合はプランを変える
4. 光回線をどうするか、次のどれかを選んで手続きする

| 選ぶもの | 内容 |
|---|---|
| 光回線を解約する | 定期契約の途中なら解約金がかかる |
| ドコモ光にプラン変更する | 手続き完了まで10日ほど。プロバイダ変更手数料3,300円がかかる |
| ほかの光回線に乗り換える | 事業者変更・光回線再利用。定期契約の途中なら解約金がかかる |
| 別のahamo回線とペアを組み直す | 家族のahamo回線などに設定し直す（このときは手順2の解除ではなく、ペア回線の設定変更になる） |

**どれも手続きしないと、後日強制解約になります**。スマホの乗り換えだけを先に済ませて光回線を放置しないよう、順番に気をつけてください。

ペア回線の解約やMNPをともなう手続きは、ドコモ インフォメーションセンターかドコモショップ／d gardenで受け付けています。

> 出典：[「ahamo光」のペア回線の解約またはプラン変更をご希望のお客さま（PDF）｜NTTドコモ](https://www.docomo.ne.jp/binary/pdf/internet/hikari/notice/ahamohikari_step_notice.pdf)

## 解約日は、申し込んだ月の翌月末まで選べる

公式の解約ページには、次のように書かれています。

| 項目 | 条件 |
|---|---|
| 解約日の指定 | 申し込み日の翌月末まで指定できる |
| 取り消し | 解約日以降はできない |
| 解約日・廃止工事日の変更 | 7日前までに連絡する |
| 解約月の基本料 | 日割りにならず、1か月分 |
| 乗り換えるとき | 新しい回線の開通日に合わせて解約日を決める |

解約月の基本料は日割りにならず、1か月分です。月の途中を解約日にしても、その月の料金は満額。**使えるうちは使うなら、解約日は月末を指定**しておくと、払った分を最後まで使えます。

ほかの光回線に乗り換える場合は、新しい回線の開通日より前に解約日が来ると、ネットが使えない日ができます。乗り換え先の開通日を先に決めてから、解約日を合わせてください。

更新期間（解約金0円）を狙う場合も、解約日を更新期間の中に指定すれば、申し込みは前の月に済ませておけます。

解約金は、手続きをした月の利用分と一緒に請求されます。月の1日に手続きした場合だけ、前の月の利用分と一緒に請求されます。

## ahamo光の解約手順：申し込みから最後の請求まで

解約の申し込みは、次の3つの窓口でできます。

```
Web           24時間受付（ahamo光が登録されたdアカウントでログイン）
ドコモショップ／d garden
電話           ドコモ インフォメーションセンター
```

申し込みから最後の請求まで、流れはこうなります。

1. **申し込む**：Web・ドコモショップ・電話のどれかで。解約日（申し込み月の翌月末まで）を指定する
2. **受付完了メールを確認する**：Webの場合は必ず確認。ドコモの紹介ページでは、手続き完了まで4日ほどかかるとしています
3. **取り外し工事・機器返却の連絡を待つ**：宅内機器の取り外し工事の調整で、ドコモ光サービスセンターから連絡が来る場合があります。機器の返却を求められたら、すぐに返す（返さないと機器相当額を請求されることがある）
4. **最後の請求を確認する**：解約月までの料金は翌月に請求されます。解約金や工事料の残りが入っているかを確認する

一体になっているプロバイダの契約も、同時に解約されます。廃止の工事より前に、インターネットが使えなくなる場合も。

## ほかの光回線に乗り換えるとき

フレッツ光の設備を使うほかの光回線（光コラボ）に乗り換えるときは「事業者変更」、別の回線事業者に乗り換えるときは「光回線再利用」になります。自分の乗り換え先がどちらに当たるかは、乗り換え先に確認してください。どちらの場合も、先にドコモで承諾番号を取り、その番号で乗り換え先に申し込みます。

- 承諾番号の有効期限は、**発行日を含めて15日間**
- 工事料を分割で払っている途中なら、**承諾番号を取った時点で残りを一括で精算**
- 定期契約の途中なら、解約金がかかる
- ahamo光 10ギガは、そのままでは事業者変更できない。先に1ギガへの変更（工事あり）が必要
- 乗り換えが完了した月の基本料は、日割りにならない

ここまでで、解約の手続きに必要な情報はそろいました。解約する人は、[ドコモの解約ページ](https://www.docomo.ne.jp/internet/hikari/procedure/cancellation/)から手続きしてください。スマホのahamoもやめる人は、先に[ペア回線の手続きのPDF](https://www.docomo.ne.jp/binary/pdf/internet/hikari/notice/ahamohikari_step_notice.pdf)で自分のパターンを確認してください。契約を検討している人は、よくある質問のあとの章を読んでください。

## ahamo光の解約についてよくある質問

**Q. ahamoだけ解約して、ahamo光は残せますか？**
A. そのままでは残せません。選べる道は「スマホのahamoをやめると、ahamo光はどうなる？」の表にまとめています。

**Q. ahamo光だけ解約して、スマホのahamoは続けられますか？**
A. 続けられます。光回線の解約手続きだけで済みます。更新期間以外なら、光回線の解約金はかかります。

**Q. 解約金がかからない月はいつですか？**
A. 契約満了月とその翌月・翌々月の3か月です（解約金の章）。

**Q. 途中でやめても、もらったdポイントは返さないといけませんか？**
A. 今回確認した特典ページには、もらったdポイントを返す決まりは書かれていませんでした。書かれているのは、解約月の翌月から付与が終わることです。

**Q. 10ギガのまま、ほかの光回線に乗り換えられますか？**
A. 事業者変更はできません。先に1ギガへ変更（工事あり）してから申し込みます。日程に余裕をもって手続きしてください。

## 契約を検討している人へ：ahamo光が向いている人

ahamoを使っている人しか申し込めない光回線です。月額はマンションタイプ3,630円（1ギガ・2年契約）で、ドコモ光セット割の対象外です。

- **向いている人**：ahamoを2年以上使い続ける予定で、今の部屋に長く住む人
- **注意が必要な人**：1〜2年以内にスマホの乗り換えや引っ越しをする可能性がある人。工事料実質0円のdポイントが途中で止まり、スマホを乗り換えるとahamo光も手続きが必要になります

マンションの月額は、比べた4社の中でおてがる光に次ぐ安さでした。違約金・工事費の残り・1〜3年の総額まで比べた結果は[一人暮らしの光回線4社比較](/articles/hikari-internet)に載せています。

申し込む前に確認してほしいのは、月額だけではありません。途中でやめたときの工事料の負担と、スマホのahamoを続ける予定です。この2つに納得できたら、申し込みページで最新の料金・工事料・特典の条件を確かめてください。

## まとめ：解約する前に確認すること

- **解約金**：1ギガはマンションタイプ3,630円・戸建タイプ4,950円、10ギガは5,610円。契約満了月と翌月・翌々月なら0円
- **工事料**：分割払いが残っていれば、解約月の翌月に残りを一括で請求される
- **dポイント**：工事料実質0円特典の進呈中に解約すると、解約月の翌月から進呈が止まる
- **スマホのahamoもやめる場合**：スマホ側の手続きより先に、ahamo光のペア回線の手続きが必要。放置すると強制解約

解約を申し込む前に、My docomoで契約満了月と工事料の分割の残りを確認してください。続けるか乗り換えるかで迷っているなら、月額だけでなく、やめるときの費用も含めて比べてください。
