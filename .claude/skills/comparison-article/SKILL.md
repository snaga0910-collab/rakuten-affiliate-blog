# 比較記事の基準

このブログの記事は**数字を扱う記事**です。外部の添削で繰り返し指摘されたのは、文章力ではなく**計算の透明性**でした。以下はその指摘をルール化したものです。

書く前に読み、書いたあとに `npm run check` を通してください。

## いちばん大事なこと

**比較記事は「結論」より「再計算できること」が信頼につながります。**

読者が同じ数字を出せない記事は、どれだけ文章が上手くても比較記事として成立しません。文章表現をいじる前に、表と計算根拠を固めてください。

## 0. 比較の単位は「実在する1商品・1契約」にする

**これがいちばん優先です。文章を書く前に、ここを固めてください。**

カテゴリの最安値を寄せ集めると、**誰も買えない金額**ができあがります。

```
やってはいけない
  本体の最安値      3,630円（クリンスイ）
  カートリッジの最安値  年3,900円（ブリタ）
  合計          7,530円   ← この構成の商品は存在しない

正しい
  クリンスイ CB073W-WT ＋ CBC03  初年度 6,622円
  ブリタ リクエリ ＋ マクストラプロ  初年度 15,890円
```

過去の失敗：水の記事で上のとおりの合成をやり、外部監査で点数が78点から72点に下がった。「よく調べた個人ブログ」で止まる原因はここだと指摘された。

**消耗品の年間費用を出すときは、必ず次を商品ごとに確認します。**

- 交換・補充の**目安期間**（公称値。「3か月ごと」など）
- **総ろ過水量・総使用量の上限**（「900L」など）
- **本体に付属する消耗品の数**（初年度はその分を差し引く）

**交換は「期間」と「使用量の上限」の早く来たほうで決まります。** 一律に「年4個」と置かないこと。同じ水の記事で、ブリタは4週間ごと（年13個）、クリンスイは3か月ごと（年4個）で、**カートリッジ単価が安いブリタのほうが年間では2倍以上高くなりました**。

## 0-2. 「総額」の定義を1か所で固定する

**「初年度費用」「年間総額」と書くなら、何を含むかを表の直下で一度だけ明文化します。**

- 初期費用を含むか
- 電気代・送料など、公表されていない費用があるとき**どう表示するか**
- 出しているのは**最低額かレンジか**
- タイトルや冒頭の数字は**何を含んだ数字か**

過去の失敗：タイトルに「初年度6,622円から96,700円」と書いたが、96,700円は電気代の**下限**を使った金額だった。上限なら106,300円。読者は確定値だと受け取る。

**非公表の費用がある会社を同じ表に並べるときは、「同じ条件の総額ではない」と明記します。** 一方に電気代を足し、他方には足さないまま順位のように並べると、比較の公平性を疑われます。

## 0-2b. 比較表の列で、確定値と不確定値を分ける

**「同じ条件の総額ではありません」と注記するだけでは足りません。** 電気代込みの商品と非公表の商品を同じ「初年度費用」の列に並べると、読者は順位を誤解します。

```
悪い（1列にまとめて注記で断る）
  | 商品 | 初年度 |
  | A   | 96,700円 |
  | B   | 31,860円＋電気代 |

良い（列を分ける）
  | 商品 | 初年度（電気代を除く） | 公表電気代 | 初年度合計 |
  | A   | 91,900円 | 4,800〜14,400円 | 96,700〜106,300円 |
  | B   | 31,860円 | 非公表        | 31,860円＋電気代 |
```

**非公表を0円のように見せないこと。** 「非公表」と書く列があれば、比較できる数字と不確定な数字が混ざりません。**合計が算出できない商品は「算出できません」と書き、順位付けしない。**

**そして、この形を記事内の全部の表に適用します。** 主要な比較表だけ3列にして、カテゴリ別の表が古い形のまま残っていると、読んだ人はそちらで判断します。列名も「1日2L・年」ではなく「1日2L・年間費用（電気代を除く）」まで書く。**表は本文より厳密であるべきです。**

**本文で2社を比べるときも、条件をそろえた金額どうしで比べていると明記します。** 片方が電気代込み、片方が電気代抜きのまま「こちらが安い」と書くと、表の丁寧さが台無しになります。

## 0-2c. 「N倍」は、何と何のN倍か毎回確かめる

同じ記事の中に複数の指標があると、倍率を取り違えます。

過去の失敗：浄水器2商品で「年間ではクリンスイの2.4倍」と書いたが、2.4倍は**初年度総額**の比。年間の維持費で比べると2.1倍だった。

- 見出しと本文で**違う指標を使わない**
- 使うなら「初年度総額では2.4倍、年間の維持費では2.1倍」と**両方書く**
- 記事を書き終えたら、**倍率をすべて電卓で検算する**

## 0-3. 分類は最初に固定し、1つのサービスを2カテゴリに置かない

**同じサービスが2つのカテゴリに登場すると、比較の前提が崩れます。**

過去の失敗：アクアバンクを「浄水型サーバー」と「天然水サーバー」の両方の表に載せ、「同じ金額で載せています」と注記した。**「天然水」という商品属性と「サーバー」という提供形態を混ぜていた**のが原因。

- **提供形態で分類する**（水道水を注ぐ／配送してもらう）
- カテゴリの定義は**比較表より前**に置く
- 略称を使うなら、**最初に「以降は〜と略します」と宣言**する

分類を直すと数字も変わります。前の原稿の「最安どうしで11.4倍」は、分類が壊れていたときの数字でした。

## 1. 計算条件を最初に明文化する

記事の冒頭近くに「計算のルール」の表を置きます。最低限これらを明記します。

| 項目 | 書くこと |
|---|---|
| 使用量・使用頻度 | 何を前提にしたか。複数パターンなら全部 |
| 初期費用 | 含めるか、含めないか |
| ランニング費用 | 電気代・送料など、含めるものと含めないもの |
| 最低注文量・最低利用期間 | 使用量だけでは支払額が決まらない場合の扱い |
| 調査日 | いつ時点の価格か |

**「同じ量で比較しました」と書くだけでは足りません。** 最低注文量があるサービスは、使う量を減らしても支払額が減りません。その場合は「使用量を基準にするが、支払額は契約条件に従う」と書き、個別に本文で説明します。

過去の失敗：水の比較記事で「同じ飲む量で計算」と書いたが、フレシャスには2か月連続で配送を止めると月1,100円の休止手数料があり、少量利用では支払額が減らなかった。

## 2. 数字を後出ししない

**冒頭で提示する数字と、比較表の数字の条件をそろえます。**

過去の失敗：「いちばん安い年3,900円」と冒頭に出しておいて、本文の後半で「本体が別に3,630円かかります」と書いた。読者から見ると数字の見せ方がズルい。

- 初期費用があるなら、**初年度の合計**を先に出す
- 維持費だけで比べるなら、**維持費どうしの比較だと明記**する
- 「N倍の差」と書くときは、**何と何を比べたN倍か**を同じ文の中で示す

## 3. 表の中で矛盾しない

表の「内訳」列に電気代と書いておいて、注記で「電気代は含めていません」と書くのは矛盾です。

**含めないものは、表に列を作って「別途」と書く**か、**表の直下に注記を置く**。FAQまで後回しにしないこと。重要なコストほど早く出します。

## 4. 一次情報を記事内で追えるようにする

「楽天市場を見ました」「当サイトの各比較記事で調べた実額」だけでは、この記事単体で根拠が完結しません。

**最低限これを書きます。**

- 調査した商品名・サービス名（一覧表にする）
- 調査日
- 送料込みか、税込か
- 計算式（`年間費用 ＝ 何＋何＋何`）

内部リンクは便利ですが、リンク先を読まないと計算根拠が分からない状態は避けます。

## 4-2. 出典が追えない数字は載せない

「各社の公表値と実測レポートの幅」のような書き方は、**誰のどの調査か分からないので使えません**。

- 公表値を使うなら、**公表している会社だけ**挙げる
- 公表していない会社は**「記載なし」と書く**。推測で埋めない
- 第三者の実測値を使うなら、測定条件・出典・機種まで書く

過去の失敗：電気代を「年4,800〜14,400円」と1本のレンジで出したが、これは公表値と出所不明の数字を混ぜたものだった。会社ごとに分け、非公表は非公表と書き直した。

## 5. この記事が比較していないことを書く

**費用を比べた記事で、品質の優劣まで結論づけないこと。**

過去の失敗：水の記事で「差のほとんどは水質ではなく手間」と書いた。しかしこの記事は水質を比較していないので、水質差の重要度を判断する根拠がない。

正しい書き方：「今回の費用差の内訳は、水そのものの値段に加えて、冷水温水・配送・運搬の手間です。水質の優劣そのものは、この記事では比較していません。」

同じ型の失敗：

- 価格差だけを見て「香りに払う差」と断定（価格差の内訳は分からない）
- 「使う量が増えても一定です」（総ろ過水量の上限がある商品では一定にならない）
- 「量に関係なく浄水器が安い」（費用だけの話。少量なら差は縮まる）
- 「サーバーは3〜6年の契約」（一般論として断定せず「今回比較したサービスは」と限定する）
- 「浄水器の次に安い」（レンジどうしの比較で順位を断定しない）
- レビュー件数から「件数が増えると評価は下がりやすい」と一般論を導く（数件では証明できない）
- 「香りの好みが合うかどうかが全て」（単価・容量・素材も選択軸として残る）

## 6. 読者の判断を残す

「費用が同じなら配送のほうが合理的」のような断定は、読者の事情を無視しています。置き場所がない部屋なら結論が変わります。

**「〜な人には便利です。ただし〜な場合は別の選択もあります」**の形にします。

## 6-2. 調査対象は「条件を固定して、該当を全部」

「価格帯が分かれるように5点選びました」は、**差を大きく見せるために選んだように読まれます**。

```
悪い  価格帯が分かれるように5点を選んだ
良い  レビュー1,000件以上・評価4.5以上・送料込み・単品購入可の上位5件をそのまま全部
```

**条件を先に固定し、該当したものを順に載せる。** 選定の意図が入る余地をなくします。

商品性が違うものが混ざったら、その旨を書きます（例：最高額の商品が温泉水で、一般的なミネラルウォーターとは商品性が違う）。

## 6-3. 判断フローは1問1条件にする

過去の失敗：「冷水・温水がすぐ要るか、定額で使いたいか」と2条件を1問に混ぜた。温水は要らないが使用量が多いので定額を検討する人がいるので、別の質問にすべきだった。

**1問につき1条件。** 分岐したあとに次の質問を置きます。

## 6-4. 本文の数字は丸め、表で正確に出す

「浄水器との差は年4,646円」は精密すぎて、かえって計算機械の出力に見えます。

```
本文  年約4,600円
表   4,646円
```

読者が判断に使うのは概数です。1円単位の正確さは表の役目です。

## 6-4b. 判断に必要な情報は、リンク先に逃がさない

「今回比較した3社は、いずれも契約期間があります。3年・5年・6年と会社によって違い」とだけ書くと、**どこが3年でどこが6年かが分かりません**。

詳しい記事へのリンクがあっても、**判断に必要な最低情報は本文に表で残します**。

```
| 社・プラン | 最低利用期間 | 途中解約したとき |
```

## 6-4c. 主観の副詞を、数字に置き換える

```
悪い  ペットボトル：月12Lなら、意外と高くない
良い  ペットボトル：月12Lなら浄水器との差は年4,646円
```

「意外と」は誰にとって意外なのか分かりません。**数字が記事の武器なら、見出しでも数字で勝負します。**

同じ型：「たいてい」「かなり」「地味に」。使ってはいけないわけではありませんが、**根拠のある数字の直前には置かない**こと。

## 6-4d. 結論の断定に、調査範囲の条件を残す

本文で「調査した範囲で」と丁寧に書いておいて、結論だけ「費用だけなら浄水器です」と言い切ると、本文の慎重さが消えます。

```
悪い  費用だけなら浄水器です
良い  今回調査した条件では、費用を最優先するなら浄水器です
```

## 6-5. 検索語の意味の幅を、冒頭で狭める

「一人暮らし 水代」で検索する人には、**水道料金を知りたい人**も混じります。記事が飲み水の費用の話なら、冒頭で明示しないとその人は離脱します。

```
この記事で比べるのは水道料金ではなく、
浄水器・ペットボトル・ウォーターサーバーにかかる費用です。
```

**「最安」「いちばん安い」の範囲も同じです。** 市場全体なのか調査対象内なのかを書きます。「本記事で調査した範囲で」の一言で足ります。

## 6-6. 前提の数字には、用途を1語添える

「1日2L」だけだと「毎日2L飲むのか」と受け取られます。

```
悪い  1日2L（年730L）
良い  1日2L（飲用・料理用として毎日使う想定・年730L）
```

## 7. FAQは本文のコピペ置き場ではない

本文を読んだ人にとって新しい情報がないFAQは意味がありません。**検索意図の強い質問**を入れます。

良い例：

- 水道水をそのまま飲んでも大丈夫？
- 月に何L以上使えば得？
- 引っ越しが多い人はどれを選ぶべき？
- 浄水器は本当にペットボトルより安い？

悪い例：本文の見出しをそのまま疑問形にしただけのもの。

## 8. タイトル

- **32字以内**（検索結果で切れる）
- **比較対象が分かる**こと。「4通り比較」だけでは何の4通りか伝わらない
- 数字を入れるなら、本文の数字と条件が一致していること
- 「おすすめ比較N選」は使わない（大手比較メディアと同じ型で勝ち目が薄い）
- **タイトルの数字と、比較表の中身を必ず突き合わせる**

過去の失敗：「市販マウスウォッシュ6商品比較｜リステリン・モンダミン・GUM」と付けたが、中身は洗口液3つと歯間ケア3つで、GUMはフロスだった。記事の結論もフロス推しだった。

## 9. CTAは説明ではなく次の疑問につなげる

内部リンクを「くわしくは〜」で終わらせない。

```
悪い  くわしくは浄水器カートリッジ6商品の比較に書いています
まし  浄水器6商品の年間カートリッジ費用を比較する →
良い  本体価格が安い浄水器を選ぶと、かえって高くつく場合があります。
      6商品の年間交換費用を見る →
```

**リンク先に何があるかではなく、クリックすると何が解決するかを書きます。** 読者にクリックする理由を渡すためです。

**リンクの文言と、リンク先の中身をそろえること。** 本文で2社しか出していない記事から「3社を比較する」と送ると、読者は面食らいます。

## 9-2. 結論は説明ではなく断定で終える

ここまで読んだ読者に、同じ判断基準をもう一度説明する必要はありません。

```
悪い（表で条件を再説明）
  温水が不要・料理にも使う → 浄水器 6,622円〜

良い（断定）
  費用だけなら浄水器です。初年度6,622円から。
  温水が毎日必要なら浄水型サーバーです。31,860円から。
```

## 10. 文章の癖

`npm run check` が数えます。閾値を超えたら直します。

| 項目 | 目安 | 理由 |
|---|---|---|
| 太字 | 1000字あたり6回まで | 多いと強調が強調として働かない |
| 同じ文末 | 15%まで | 意味ではなくリズムでAIっぽくなる |
| 「AではなくB」 | 1000字あたり1回まで | AI検出で上位に来る型 |
| 見出しの使い回し | 全記事の8割未満 | 全記事に同じ節があると型の印になる |

**「この記事が役に立たない人」は良い節ですが、全記事に置くと誠実さの印ではなくテンプレートの印になります。** 記事ごとに言い方を変えるか、置かない記事を作ってください。

## 書いたあとに必ず

```bash
npm run check
```

- **エラーが出たら直す**（アスタリスクの露出・タイトル32字超）。ビルドが止まります
- **警告は数えた結果**。閾値を超えた項目は直す

アスタリスクの露出は、閉じる `**` の直前が記号（`%` `）` `」`）のときに起きます。CommonMark の規則なので、日本語では自然に踏みます。直し方は `npm run check` の出力に出ます。

# 高得点だった記事から

外部監査で95〜96点がついたオーラルケアの記事（改訂版）で効いていた要素です。上のルールと重複しない部分だけ挙げます。

## 迷いに先に答える

記事の前半に、**読者がいちばん迷っていることへの答え**を置きます。商品の説明より前です。

```
見出し例  マウスウォッシュとフロス、結局どっちを優先すべき？
```

「AかBか」で迷っている読者に、**「両方だが、順番はこう」**と答えると、そのあとの比較が読みやすくなります。監査で「検索意図のど真ん中」と評価された箇所です。

## 選び方の基準を、比較表の前に置く

いきなり商品を並べず、**何で選ぶかを先に示します**。

```
① アルコールあり・なし（刺激）
② 成分の種類
③ 1回あたりのコスト
④ 使うシーン・携帯性
```

基準を先に読ませると、比較表が「意味のある表」になります。

## 比較表に入れる列

価格だけの表は評価されません。最低限これらを入れます。

```
商品 / 価格 / 1回あたりの目安 / 特徴（刺激・タイプ） / 使うシーン / おすすめな人
```

**「おすすめな人」の列があると、読者は数字を全部読まなくても自分に当てはめられます。** 余裕があれば「主な成分」「内容量」も足すと比較軸が増えます。

## 途中に小さなまとめを挟む

長い比較のあとに、3行程度のまとめを入れます。

```
携帯性で選ぶなら → モンダミン（約37円）
使用感を求めるなら → リステリン（約20円）
コスト重視なら → コンクール（約3円）
```

最後まで読まない人にも結論が届きます。

## 実体験は、使った商品にだけ書く

**使っていない商品に体験談を書かないこと。** 監査でもE-E-A-Tの観点で望ましいと評価されました。

使っていない商品は、レビュー傾向や仕様から評価していると分かる書き方にします。捏造するより、書かないほうが信頼されます。

## 結論で背中を押す

「自分に合うものを選んでください」で終わらせません。

```
悪い  自分に合う1本を選んでみてください
良い  まずは480円のGUMから始めるのがおすすめです
```

**いちばん外れにくい選択肢を1つ名指しする**と、読者は動けます。売り込みではなく、迷いを終わらせるためです。

ただし**記事の論理と一致させること**。本文で「温水が要るかで決まる」と書いておいて、結論で「迷ったら浄水器」に戻ると論理がブレます。読者のタイプ別に分岐させる表を置くほうが確実です。

```
温水が不要・料理にも使う   → 浄水器
飲む量が少ない・契約したくない → ペットボトル
温水が要る・水道水ベースでいい → 浄水型サーバー
産地や成分で選びたい      → 天然水サーバー
```
