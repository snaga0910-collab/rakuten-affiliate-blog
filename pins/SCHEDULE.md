# ピン投稿スケジュール（2026-08-21 作成）

**1日3枚ずつ、16日で48枚。** まとめて出さない理由は2つ。

1. **Pinterestは継続投稿を評価する。** 30日で到達5人という状態なので、
   アカウントが「動いている」と判定されることが効く可能性がある
2. **効果の切り分けができる。** まとめて出すと、伸びたときに
   どの枚が効いたのか分からなくなる

投稿文と画像は [POST.md](POST.md) にある。ボードは各記事の指定どおり。

---

## 優先の考え方

**A8案件が入っている2記事を最初に出す。** 1件7,500〜9,500円で、
楽天（1件90〜300円）とは桁が違う。流入が1件でもあれば効果が大きい。

次に**8/11の分析でクリック率が高かったジャンル**を出す。

| ジャンル | 8/11時点のCTR |
|---|---|
| オーラルケア | 9.2% |
| コーヒー | 6.4% |
| 柔軟剤 | 4.5% |
| 浄水器 | 2.4% |
| バスマット・食洗機・替えブラシ | 0% |

**0%だった3ジャンルは最後に回す。** 新デザインで変わるか見るために出しはするが、
限られた枠を先に使う理由がない。

## 見るべき数字

**1週間後（Day 7 時点）に Pinterest アナリティクスで確認する。**

| 指標 | 8/15時点 | 見方 |
|---|---|---|
| 保存数 | **0** | ここが動けばデザイン変更が効いた |
| アウトバウンドクリック | **0** | ブログへの流入。0のままなら別の原因 |
| 合計オーディエンス | **5人** | 分布そのもの。増えなければ配信されていない |

**保存数がいちばん重要。** Pinterestは保存を表示回数に反映するので、
ここが0のままだと何枚出しても頭打ちになる。

旧デザイン36枚は30日間ずっと保存0だった。**新デザインで1つでも付けば差が出たと言える。**
